# 기획 AI 협업 가이드

더라운지 3.0 기획팀에 공유하기 위한 **기획자와 AI의 협업 가이드**입니다. 요구·현행 분석부터 IA 구성, 화면·정책 설계, 검수와 개발 전달까지 AI와 함께 진행하는 방법을 정리했습니다.

기획자는 기획 범위와 정책 판단을 맡고, AI는 자료 조사·대조, 초안 작성, 누락·충돌 점검을 지원합니다. 현업 요구·AS-IS 화면·공유된 결정을 함께 확인하고, 근거가 남는 산출물을 기준으로 다음 작업을 이어가는 것이 핵심입니다.

> 이 문서는 **초안**입니다. 기획팀 검토 후 용어·양식·운영 위치를 확정합니다.

**[기획 AI 협업 가이드 — index.html](index.html)**을 브라우저에서 열면 전체 흐름과 요청 예시를 볼 수 있습니다. 폴더를 내려받아 `index.html`을 열어도 됩니다.

## 시작하기

1. `index.html`에서 협업 흐름과 시작 예시를 확인합니다.
2. AI에게 이 가이드의 `AGENTS.md` 경로, 대상 기획 자료(IA 엑셀·PPT·Figma), 공유 기록 위치를 전달합니다.
3. 이번 요청이 현행 분석·IA·화면/정책 설계·검수 중 어디까지인지 지정합니다.
4. 작은 실제 작업 하나로 자료 읽기, 대조, 결과 기록이 이어지는지 확인합니다.

AI에 전달할 첫 요청은 아래처럼 작성할 수 있습니다. `<...>` 부분은 실제 경로와 작업 내용으로 바꿉니다.

```text
기획 협업 가이드: <이 폴더의 AGENTS.md 경로>
기획 자료: <IA 엑셀·PPT·Figma 링크와 버전, 검토 범위>
현행(AS-IS) 자료: <화면 목록·운영 화면 캡처 / 없다면 없음>
공유 기록: <결정·작업 기록 위치 / 미정이면 미정>

작업: <대상 메뉴·기능과 요청 범위>

가이드의 AGENTS.md를 읽고 이번 작업에 필요한 스킬을 적용해줘.
자료의 파일·시트·슬라이드 근거를 남기고, 확인한 사실과 추정·미정을 구분해줘.
원본은 수정하지 말고 결과는 별도 파일로 만들어 남은 확인 사항을 기록해줘.
```

가이드를 산출물 폴더 밖에 두는 경우 AI가 자동으로 읽는다고 가정하지 않습니다. 새 대화나 작업 재개 시에도 가이드와 대상 자료·공유 기록 위치를 전달합니다. 별도 스킬 등록이나 외부 번들 설치 없이, 이 폴더의 지침과 필요한 `SKILL.md`를 읽는 방식으로 시작할 수 있습니다.

## 적용과 운영

이 자료는 더라운지 3.0 기획 작업에서 반복되는 절차를 정리한 협업 기준입니다. 실제 산출물 템플릿, 화면 ID 체계, 승인 절차는 프로젝트에서 합의한 기준을 따릅니다. 업무 정책은 현업의 승인된 자료·공유 결정을 확인하고, 미정 사항은 결정 주체와 영향 화면을 기록해 확인합니다.

팀의 결정·IA·설계서는 기존에 쓰는 공유 위치에 남깁니다. 이 폴더의 기록 양식은 참고해 사용하되, 개인 복사본마다 팀의 결정을 따로 관리하지 않습니다. 가이드를 복사해 사용할 때는 원본 위치와 기준 버전 또는 배포일을 함께 남깁니다.

완료 여부는 산출물의 근거·검수 결과와 현업 확인 상태를 기준으로 판단합니다. 확인하지 못한 자료와 남은 정책 결정은 구분해 기록하고, 사용 중 드러난 문제는 공통 지침과 스킬에 반영합니다.

화면 테마(`assets/`)와 문서 구성은 더라운지 [백엔드 AI 개발 가이드](https://minsukong.github.io/dev_guide/)를 따랐습니다.
