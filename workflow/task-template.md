- 담당 / 영역·채널·모듈:
- 공유 작업 링크·관련 결정 ID / 적용한 가이드 버전·배포일: 해당할 때
- 기준 자료: 파일명·버전·시트/슬라이드/화면 링크·확인 날짜
- 진행 상태: Todo / In Progress / Review / Done / Blocked
