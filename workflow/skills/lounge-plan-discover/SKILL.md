# lounge-plan-discover — 요구·현행 분석

## 역할과 선택 기준

흩어진 요구와 현행 시스템을 기획이 쓸 수 있는 목록으로 바꾸는 단계다. "현행 화면 정리해줘", "보고서에서 이 메뉴 요구만 뽑아줘", "현업이 요청한 게 IA에 다 들어갔는지 봐줘" 같은 요청에 사용한다. 정책을 결정하거나 TO-BE 화면을 설계하는 단계는 아니다. 요구가 이미 정리돼 있으면 IA 구성·대조나 화면·정책 설계부터 시작할 수 있다.

## 필요한 입력과 조사 범위

정리된 요구 정의서나 현행 화면 목록이 있다는 전제는 없다. 실제로 제공된 자료만 근거로 쓰고, 없으면 확인 가능한 사실과 추가로 필요한 자료를 먼저 정리한다.

- 필수: 대상 영역·메뉴와 분석 목적, 읽을 수 있는 요구 자료(보고서·회의록·현업 메일) 또는 현행 자료(AS-IS IA·화면 캡처·운영 URL 목록).
- 관련 근거: 이전 분석 결과, 결정 기록, 프로젝트 기획 문서. [프로젝트 문서 연결 기준](../../planning.md#project-docs)에 따라 관련 부분만 읽는다.
- 범위: 대상 메뉴의 사용자·운영자, 주요 업무 흐름, 전후 메뉴. 자료를 읽지 못한 것을 요구 누락으로 단정하지 않는다.

## 작업

1. 대상 자료의 파일·버전·시트/슬라이드를 확인하고 읽기 범위를 기록한다. 같은 자료의 버전이 여럿이면 기준본을 먼저 확인한다.
2. 요구는 한 행에 하나씩, 출처(파일·슬라이드·회의 일자)와 함께 적는다. 요구를 요약하면서 조건·예외를 빼지 않는다.
3. 요구를 업무 정책 / 화면·기능 / 운영·데이터 / 비기능(보안·성능·인증)으로 나눈다. 분류가 애매하면 둘 다 표시한다.
4. 현행 화면 목록은 [화면 단위 기준](../../planning.md#ia-unit)으로 정리한다. 외부 화면·비화면 로직·공통 컴포넌트·중복 진입은 별도 시트에 사유와 함께 남긴다.
5. 현행 운영에서만 쓰는 우회 방식(수기 처리·엑셀 업로드·고객센터 처리)을 찾으면 요구 후보로 표시한다. 이런 기능은 IA에 메뉴로 드러나지 않아 빠지기 쉽다.
6. 자료끼리 다른 내용(일정·범위·용어)은 충돌로 기록하고 한쪽을 정답으로 고르지 않는다.
7. 확인이 필요한 항목은 결정 주체별 질문으로 정리한다.

산출물: 요구 목록 / 현행 화면 목록과 제외·통합 목록 / 충돌·미확인 / 확인 질문. AI 정리만으로 요구를 확정하지 않는다.

## 요구를 정리하는 판단 기준

먼저 "누가, 언제, 무엇을 하려는가"와 "지금은 어떻게 하고 있는가"를 나눠 적는다. 현행 방식을 그대로 옮기는 요구인지, 바꾸려는 요구인지 구분해야 TO-BE에서 화면을 유지할지 없앨지 판단할 수 있다.

- 요구 문장이 해결 방식만 말하면("엑셀 다운로드 추가") 그 방식으로 해결하려는 업무(정산 대사)를 함께 적는다.
- 1차/2차 범위가 언급되면 근거와 함께 표시하고, 2차로 미룬 요구가 1차 화면에 진입점을 남기는지 확인한다.
- 같은 요구가 여러 자료에 다르게 적혀 있으면 가장 최근의 승인 자료를 우선 근거로 두되, 차이는 기록한다.

## 자료 부족·충돌 처리와 다음 단계

자료를 열 수 없거나 일부만 읽혔으면 필요한 파일·권한과 미확인 범위를 남긴다. 전체 메뉴가 미정이라고 일괄 보류하지 않고, 확인된 범위는 정리해 다음 단계로 넘긴다. 정리된 요구 목록과 현행 화면 목록은 lounge-plan-ia의 대조 근거로 전달한다.

## 결과 형식과 사용 예시

```text
분석 범위·근거: <파일·버전·시트/슬라이드·확인 날짜>
요구 목록: <요구 / 분류 / 출처 / 현행 방식 / 비고>
현행 화면: <화면 수 / 제외·통합 수와 기준>
충돌·미확인: <내용 / 근거 위치 / 필요한 확인>
확인 질문: <질문 / 결정 주체 / 영향 메뉴>
```

가상 사례: 보고서에는 "BO 마케팅 메뉴 개편"만 있고, 회의록에는 "쿠폰 일괄 발급을 엑셀로 하고 있다"는 운영 의견이 있다. 현행 IA에는 일괄 발급 화면이 없다. 이 경우 '쿠폰 일괄 발급'을 요구 후보로 올리고 현행 방식(엑셀 수기 처리)과 출처(회의록 일자)를 적은 뒤, 1차 범위 포함 여부를 현업 확인 질문으로 남긴다. 실제 요구나 결정이 아니다.
